# @topiadesk/marketing-site

The public Topiadesk marketing website

Next.js (App Router) application. Default dev port **3104**.

## Develop

```bash
pnpm --filter @topiadesk/marketing-site dev      # dev server on port 3104
pnpm --filter @topiadesk/marketing-site build    # production build
pnpm --filter @topiadesk/marketing-site start    # serve the production build
```

Shared UI comes from `@topiadesk/ui`; API access from `@topiadesk/api-client`.
