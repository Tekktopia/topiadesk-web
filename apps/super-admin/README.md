# @topiadesk/super-admin

Topiadesk-internal Super-Admin portal

Next.js (App Router) application. Default dev port **3103**.

## Develop

```bash
pnpm --filter @topiadesk/super-admin dev      # dev server on port 3103
pnpm --filter @topiadesk/super-admin build    # production build
pnpm --filter @topiadesk/super-admin start    # serve the production build
```

Shared UI comes from `@topiadesk/ui`; API access from `@topiadesk/api-client`.
