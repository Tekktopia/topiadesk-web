# @topiadesk/credentials

Public certification credential verification

Next.js (App Router) application. Default dev port **3106**.

## Develop

```bash
pnpm --filter @topiadesk/credentials dev      # dev server on port 3106
pnpm --filter @topiadesk/credentials build    # production build
pnpm --filter @topiadesk/credentials start    # serve the production build
```

Shared UI comes from `@topiadesk/ui`; API access from `@topiadesk/api-client`.
